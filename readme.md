# 🎉 강의용 랜덤 뽑기 & 조 편성 웹앱

강의 및 수업 시간에 쉽고 빠르게 사용할 수 있는 **랜덤 뽑기 및 조 편성 웹앱**입니다. 인터넷 연결이나 복잡한 설치 없이 브라우저에서 바로 실행할 수 있습니다.

---

## 🛠️ 주요 기능

1. **이름 입력 및 자동 저장**
   - 참여자 이름을 한 줄에 한 명씩 입력할 수 있습니다.
   - 입력한 내용은 브라우저에 자동 저장되므로, 페이지를 새로고침하거나 창을 닫았다 열어도 내용이 유지됩니다.
2. **한 명 뽑기 (애니메이션)**
   - "한 명 뽑기" 버튼을 누르면 이름이 빠르게 돌아가다가 짜릿하게 한 명에게 멈추는 애니메이션이 작동합니다.
3. **이미 뽑힌 사람 제외 옵션**
   - 체크박스를 체크하면 이미 추첨된 사람은 다음 추첨에서 자동으로 제외됩니다.
4. **조 편성 기능**
   - 원하는 조 수를 입력하고 버튼을 누르면, 전체 인원을 무작위로 공평하게 나누어 깔끔한 표(카드) 형태로 보여줍니다.
5. **반응형 디자인**
   - 컴퓨터 화면뿐만 아니라 스마트폰과 태블릿에서도 화면이 꽉 차게 보기 편하도록 디자인되었습니다.

---

## 🚀 사용 방법 (Windows 기준)

1. 컴퓨터 **바탕화면**에 새 폴더를 하나 만듭니다 (예: `랜덤뽑기`).
2. 다운로드한 `index.html` 파일을 해당 폴더 안에 넣습니다.
3. `index.html` 파일을 **마우스로 더블클릭**합니다.
4. 평소 사용하는 인터넷 창(크롬, 엣지 등)이 열리면서 웹앱이 즉시 실행됩니다!
